<objective>
Unify adapter credential management so adapter keys live in `.env` (single source of truth), are configurable from the Settings page, and drive adapter lock/unlock state in the capability contract.

Purpose: Currently adapters show "locked" because orchestrator checks CredentialStore (empty SQLite) while adapter env vars only reach dashboard_service. Settings page has no adapter key fields. Users cannot configure adapters at all through the UI.

Output: Adapter keys configurable in Settings, persisted to .env, read by orchestrator for lock state, dashboard cards unlock after configuration.
</objective>
