<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SSE payload (unauthenticated) → rendered node labels | LLM-generated module names/categories are rendered in the UI |
| user click on a graph node → review panel data fetch | client-initiated read of module review data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-32 | Tampering | LLM-generated module name/category rendered as node chrome | mitigate | Render strictly as React text children (never `dangerouslySetInnerHTML`); node label containers already `truncate`, bounding layout-breaking payloads |
| T-08-33 | Spoofing | a module node claiming `pending_approval` it does not have | accept | Display-only; every approve/reject is re-authorized server-side by RBAC and re-validated against `ModuleStatus.VALIDATED` in `approve_module()` |
| T-08-34 | Denial of Service | unbounded module rows blowing up the graph | accept | Node count is bounded by the mounted `modules/` tree; React Flow virtualizes rendering. Revisit with pagination only if the module count exceeds the low hundreds |
| T-08-35 | Repudiation | rejected module vanishing from the graph without trace | mitigate | Rejected/failed state renders explicitly (shake + red border) and the GC sweep only removes it on a later cycle; the audit trail is independent of the graph |
</threat_model>
