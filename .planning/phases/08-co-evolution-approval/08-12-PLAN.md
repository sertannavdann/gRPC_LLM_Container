<objective>
Deliver D-07: every installed module gets a standard, auto-generated UI surface rendering its data and charts from the canonical `AdapterRunResult` envelope — modules never hand-build UI.

Purpose: `AdapterRunResult` is defined in `shared/modules/output_contract.py` and asserted by contract tests, but nothing in the running system ever produces one and no renderer consumes one. Without a backend that emits the envelope, D-07 has no data source, so this plan delivers both halves.
Output: a dashboard run endpoint, a typed fetcher, a generic `ModulePanel`, and its wiring into the existing detail panel.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → module run endpoint | a request causes LLM-generated adapter code to execute and call third-party APIs |
| adapter output (third-party data) → rendered DOM | untrusted remote content displayed to the user |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-49 | Elevation of Privilege | running a module that is not installed/approved | mitigate | The endpoint 404s unless the adapter is registered AND its manifest status is INSTALLED — the approval gate is not bypassable through the run path |
| T-08-50 | Denial of Service | repeated run calls hammering third-party APIs or exhausting quota | mitigate | Endpoint is authenticated (not in `public_paths`) and covered by plan 08-05's rate limiter; the UI runs only on explicit user action, never on mount |
| T-08-51 | Information Disclosure | credentials or full third-party payloads returned to the browser | mitigate | Only the canonical envelope is returned; credentials are resolved server-side via the existing aggregator path and never serialized; `data_points` are truncated to a bounded count |
| T-08-52 | Tampering | third-party or model-authored strings rendered as markup | mitigate | All values render as React text; artifact `bytes` are never injected as HTML; zero `dangerouslySetInnerHTML` (acceptance criterion) |
| T-08-53 | Denial of Service | an adapter hanging the dashboard event loop | mitigate | `AdapterConfig.timeout_seconds` is honoured by `BaseAdapter.fetch`, which never raises; the handler awaits a single bounded call |
</threat_model>
