RESEARCH Pitfall 4 (load-bearing): Playwright's `page.route()` interception does NOT reliably deliver events to
`EventSource` connections — SSE tests that mock the endpoint hang indefinitely. Test against a REAL running
dashboard service. This matches the repo's existing `make test-monkey` "requires services up" precedent.

ui_service — Next.js 14.2.20 app on port 3000 (see docker-compose `ui_service`), `package.json` scripts today are
`dev`/`build`/`start`/`lint` only; devDependencies contain no test framework. TypeScript `strict: true`.

Pipeline page observable state (plans 08-07/08-08): the toolbar renders a live indicator driven by
`state.matches({ connection: 'connected' })` — `Wifi` icon + the text **"Live"** in `text-green-400` when
connected, `WifiOff` + the text **"Disconnected"** in `text-red-400` otherwise. These two strings are the
E2E assertion targets. The machine's `connection` region transitions connected → reconnecting on `SSE_ERROR`
and back to connected on the next `SSE_MESSAGE`; the native EventSource auto-retries.

dashboard_service — SSE endpoint `GET /stream/pipeline-state` on port 8001, 2-second interval, listed in the
dashboard's `public_paths` (no API key needed for the stream). Container/service name in `docker-compose.yaml`
is `dashboard` — read the compose file to confirm the exact service name before scripting a restart.

Makefile conventions — targets use `@printf '$(CYAN)...$(RESET)\n'` (never `@echo`, macOS ANSI compatibility)
and Python test targets `cd tests && python -m pytest ...`. `test-e2e` is ALREADY TAKEN by a Python
orchestrator test — use a distinct target name (`ui-e2e`).

Env availability (08-RESEARCH.md): Node v26.4.0, npm 11.17.0, Docker 29.2.0 — all present.

Deviation note to record in the SUMMARY: 08-RESEARCH.md sketched `tests/e2e/` at the repo root. This plan places
specs in `ui_service/e2e/` instead, because the npm dependency tree, `tsconfig.json` path aliases, and the
Playwright binary all live under `ui_service/`, while the root `tests/` tree is pytest's. Same coverage, fewer
cross-tree resolution hacks.
