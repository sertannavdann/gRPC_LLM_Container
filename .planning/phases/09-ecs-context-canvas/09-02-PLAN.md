Expose canvas c_state to the orchestrator through the smallest possible backend seam: a Python
port of the canonical verbalizer operating on the dict `pipeline_stream._build_pipeline_state()`
already computes every 2 seconds for the SSE stream.

backend) requires a canvas tab to be open, adds a stateful ingestion endpoint, and races the SSE
stream. The backend already has every ingredient. Re-deriving c_state server-side removes the
browser from the orchestrator's context-assembly path entirely.

Output: `dashboard_service/canvas_context.py`, `GET /context/canvas`, and a pytest suite proving
byte-stability and that no credential material is emitted.
