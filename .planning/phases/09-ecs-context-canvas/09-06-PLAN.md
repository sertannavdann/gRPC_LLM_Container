    Export `const STAGE_NODE_IDS = ['stage-intent','stage-routing','stage-tools','stage-synth'] as const`

    selection on the first tick. Plan 07's `canvasGraph.ts` must import this constant rather than

    Export `pipelineNodeIds(data: PipelineState): Set<string>` building the authoritative id space

    SSE payload carries an `error` variant with no collections at all, and this helper must not throw
    inside an assign.

    Add a `clearSelectionIfMissing` action to the `actions` block of `setup({...})`, modelled on the
    existing `clearSelection` (lines 142-148) but narrower: `assign(({ context, event }) => {...})`
    that returns `{}` unless `event.type === 'SSE_MESSAGE'`; returns `{}` when
    `context.selectedNodeId` is null; otherwise computes `pipelineNodeIds(event.data)` and, when the
    selected id is absent, returns `{ selectedNodeId: null, selectedModuleId: null, review: null,
    audit: [], actionError: null }` — the same fields `clearSelection` resets, because a dangling
    selection must also drop the review payload it was showing. Return `{}` when the id is present.

    Wire the action into ALL THREE `SSE_MESSAGE` transitions in the `connection` region, converting
    each single-action string into an array in the order `['updatePipeline', 'clearSelectionIfMissing']`
    — the pipeline context must be updated before the guard reads it is NOT required (the guard reads
    `event.data`, not context), but keeping `updatePipeline` first preserves the existing reading
    order and avoids a subtle future dependency:
      - `connecting`: `SSE_MESSAGE: { target: 'connected', actions: ['updatePipeline','clearSelectionIfMissing'] }`
      - `connected`:  `SSE_MESSAGE: { actions: ['updatePipeline','clearSelectionIfMissing'] }`
      - `reconnecting`: `SSE_MESSAGE: { target: 'connected', actions: ['updatePipeline','clearSelectionIfMissing'] }`

    Do not touch the `selection` or `reviewPanel` regions, the `sseConnection` actor, or any existing
    action body. This is an additive change to a locked Phase 6 machine.
