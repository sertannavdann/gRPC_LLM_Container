## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-10 | Denial of Service | StrictMode double-invocation doubling snapshot-ring and event-log growth (Assumption A3, untested by every spike) | mitigate | `recordSync` is guarded by a `pipeline.timestamp` comparison so an identical snapshot never appends twice; ring is capacity-bounded and the log is checkpointed (plan 05); empirically verified in checkpoint check 1 |
| T-09-17 | Tampering | Mid-drag removal writing position back to an already-removed entity (Assumption A4 / Pitfall 3) | mitigate + verify | The `if (n && entity)` existence guard from plan 07 is the mitigation; checkpoint check 2 is the empirical verification the spikes recommended instead of speculative machinery |
| T-09-06 | Information Disclosure | `window.__nexusCanvas.cState()` exposing canvas topology to page scripts | mitigate | Registered only behind plan 09's guard (`NODE_ENV !== 'production'` OR the opt-in `NEXT_PUBLIC_CANVAS_DEV_SEAM=1` build flag, which the Dockerfile defaults to off); the data is the same topology the already-public SSE stream broadcasts, and entity records carry no credential values |
| T-09-24 | Tampering | Keyboard shortcut hijacking the browser's native undo inside a text field, corrupting user input | mitigate | The `keydown` handler returns early when `document.activeElement` is INPUT/TEXTAREA/contentEditable and calls `preventDefault()` only when it actually handles the event |
